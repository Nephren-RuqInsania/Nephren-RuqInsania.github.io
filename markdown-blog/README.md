# 博客写作指南

`markdown-blog/` 存放首页简介、专栏、文章和随文章维护的图片与附件。[`home.md`](home.md) 对应博客首页 `/`；本 README 只供写作时查阅，不会出现在网站或导航中。

## 创建专栏

1. 在 `markdown-blog/` 下创建一个目录，例如 `rust/`。目录名决定专栏地址，因此 `rust/` 对应 `/rust/`。
2. 在目录内创建 `index.md`，用 `title` 写导航里显示的名字，正文写专栏简介。例如 `rust/index.md`：

```markdown
---
title: Rust 学习笔记
---

记录学习 Rust 时遇到的问题和例子。
```

3. 有文章时，在同一目录下创建 `posts/`。只添加 `index.md` 也可以创建一个空专栏；反过来，**没有 `index.md` 的目录不算专栏**，即使里面已经有文章，也不会出现在导航里。

## 创建文章

文章放在所属专栏的 `posts/` 下。根据是否有本地资源，选一种形式：

| 写法 | 在 `markdown-blog/` 下的路径 | 适合 |
| --- | --- | --- |
| 单文件 | `rust/posts/ownership-notes.md` | 正文不需要本地图片或附件。 |
| 目录式 | `rust/posts/ownership-notes/index.md` | 正文和本地图片或附件一起维护。 |

两种写法都对应 `/rust/ownership-notes/`。如果一篇单文件文章后来需要配图，把它移成 `ownership-notes/index.md` 即可；**不要同时保留同名的 `.md` 和目录**，否则会因地址冲突报错。

专栏目录名和文章名用小写英文字母、数字和连字符（如 `ownership-notes`）。修改名称或移动到其他专栏会改变 URL，仅修改文件头的标题不会。`posts/` 下的 `.md` 会被当成文章，不要在这里放目录说明。

### 添加配图和附件

对于目录式文章，在 `index.md` 旁建一个 `assets/`，把图片和附件放进去，再从正文用相对路径引用。例如：

```text
rust/posts/ownership-notes/
├── index.md
└── assets/
    ├── diagram.svg
    └── example.txt
```

```markdown
![所有权移动示意图](./assets/diagram.svg)
[打开示例文本](./assets/example.txt)
```

附件在站点上也保留在文章旁边的 `assets/` 下。引用不存在的文件会报错。`assets/` 内的非隐藏文件都会公开，包括正文没有引用的文件，因此不要放入私密内容。

## 文件头元数据怎么解析

首页、专栏简介和文章都从文件开头的 **YAML 文件头**读取元数据。第一行写 `---`，填完字段后另起一行写 `---` 结束文件头；后面的内容才作为 Markdown 正文渲染。文件头本身不会显示在正文里。

文章示例：

```markdown
---
title: Rust 所有权笔记
date: '2026-11-22'
summary: 用一个例子区分移动和借用。
---

## 用引用读取字符串

这里开始写正文。
```

| 字段 | 填写规则 | 网站怎么用 |
| --- | --- | --- |
| `title` | **必填**，必须是非空文本；正文里的 `# 标题` 不能替代它。 | 用作页面标题；专栏和文章也用它作为导航里的显示名称。 |
| `date` | 文章可选。用 `YYYY-MM-DD`，建议加引号；不填时省略整行。格式不正确会报错。 | 在文章和专栏列表中显示日期，同一专栏按日期从新到旧排列。没有日期的文章排在后面，不会拿文件修改时间补上。 |
| `summary` | 文章可选，写一段简短的文本。 | 显示在专栏列表和文章标题下方，也用作页面描述；不填就不显示，不会从正文自动截取。 |

文章的**归属和 URL 由路径决定**，不是由文件头里的 `category` 或 `slug` 决定。当前也没有 `draft` 字段来隐藏文章。正文的章节建议从 `##` 开始；支持表格、任务列表、删除线和脚注等 GFM 写法，原始 HTML 按文本显示。
